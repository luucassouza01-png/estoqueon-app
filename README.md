# EstoqueOn - Reversa de Paletes CD910

Sistema de gestão de reversa de paletes para o Centro de Distribuição Assaí - CD910 Arujá/SP.

## Funcionalidades

- Controle de saldo de paletes (PBR, CHEP, Descartável, Quebrado)
- Monitoramento de SLA (3 horas)
- Gestão de agendamentos
- Histórico de operações
- Dashboard com indicadores
- Login com perfis (Admin e Operador)

## Tecnologias

- HTML5, CSS3, JavaScript
- Chart.js para gráficos
- LocalStorage para persistência
- Font Awesome para ícones

## Acesso

- **Admin:** admin / admin123
- **Operador:** (criado pelo Admin)
